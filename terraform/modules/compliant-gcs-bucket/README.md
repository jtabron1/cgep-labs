# compliant-gcs-bucket

This module provisions a Google Cloud Storage bucket that satisfies six NIST 800-53 controls by construction, so a caller cannot produce a non-compliant bucket without editing the module itself. Cryptographic key establishment (SC-12) and cryptographic protection (SC-13) are met by creating a dedicated Cloud KMS key ring and customer-managed key with 90-day automatic rotation, and protection of information at rest (SC-28) is met by binding that key as the bucket's default encryption so every object is encrypted with a key we control rather than one Google manages. Audit record retention (AU-11) is enforced through a retention policy, with object versioning enabled to preserve prior states, and the module refuses production deployments with a retention period under 365 days. Configuration settings (CM-6) are locked down through variable validation on names, environments, and retention values, plus a fixed set of compliance labels that is merged over any caller-supplied labels and cannot be removed. Access enforcement (AC-3) is met by turning on uniform bucket-level access, which disables legacy object ACLs, and setting public access prevention to enforced. The module exports a computed compliance attestation output so the enforced state can be read back and recorded as evidence after each apply.
